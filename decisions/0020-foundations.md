# 0020: Foundations

Status: Accepted · Date: 2026-11-24

## Context

The foundations table in the plan had open questions for each foundation.

## Decision

Color: orange brand hue, one accent, neutrals and four status colors, ramps in OKLCH. Typography: system fonts on mobile, Inter on web, JetBrains Mono for code, tabular figures for scores. Spacing: fixed 4 px steps. Radius: soft (8 px controls, 12 px cards, pill tags). Elevation: three levels. Motion: functional only for v1. Layering: z-index tokens from Lock In. Layout: see 0014. Icons: see 0017.

## Consequences

- A signature animation, a large-screen display mode and a logo are parked for after 1.0.
