# 0005: Web, iOS and Android ship at launch

Status: Accepted · Date: 2026-11-24

## Context

VolleyXP's users are players and organizers on their phones as much as on laptops.

## Options considered

- Web first, native later.
- All three at launch.

## Decision

Every core component ships on web, iOS and Android before 1.0. How native is built is decided in 0008.

## Consequences

- A component reaches Beta only when every target platform is done.
